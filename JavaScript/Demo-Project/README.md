# Airbnb Clone (Demo)

A short demo Airbnb-style booking app built with **React** (frontend) and **Node.js** (backend API).

## Project Structure

- `client/` - React frontend
- `API/` - Node.js backend

## Quick Start

1. Install frontend dependencies:
   - `cd client`
   - `npm install`
2. Install backend dependencies:
   - `cd ../API`
   - `npm install`
3. Start backend server (from `API/`):
   - `npm run dev` or `npm start`
4. Start frontend app (from `client/`):
   - `npm start` or `npm run dev`

## Notes

- Make sure both frontend and backend are running at the same time.
- Update environment variables (API URLs, database config, secrets) based on your local setup.

## Tech Stack

- React
- Node.js
- JavaScript
